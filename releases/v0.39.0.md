# v0.39.0

- 查知識與出報表（進階模式）：`read_knowledge` 的 `search` 改成兩層讀法的第一層：只列名稱、種類、狀態與簡短定義，以及字詞點名的表與欄位（各一行），不再附附註；依簡短定義挑看起來相符的概念，再用 `definition` 或 `trace` 展開。
- `definition` 與 `trace` 附上這個概念讀的欄位與表的附註（`notes`）；`trace` 把知識缺什麼（`lacks`）與 `compile_query` 會問人的問題（`compile_asks`）分開列。
- 需要 Ophion `feat/two-level-search`。
