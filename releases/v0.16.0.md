# v0.16.0

- 進階模式的 sql-path 改成先確認、再補洞（出報表與建立 pview 共用）：
  - `compile_query` 有洞時回覆只有 `reading`、`holes` 與 `expects`，補齊了才有 `sql`。
  - 問洞的 `question` 之後，用 `read_knowledge`、`read_schema` 與 `expects` 找到要讀的欄位，向使用者提議，確認後才補。
  - `fills` 帶片段，`answers` 帶使用者的原話；`reading` 由編譯器列出每個回答與它補的概念。
  - 補齊後回傳的 `sql` 是最佳化過、實際執行的那份，別名與結構可能和寫片段時不同。
