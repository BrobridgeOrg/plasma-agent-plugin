# v0.15.0

- 進階模式的 sql-path 新增「關聯洞」的補法（出報表與建立 pview 共用）：
  - `compile_query` 對知識庫裡尚未經 Plasma 驗證、無法驗證或被推翻的關聯留下 `relation_unverified`／`relation_refuted` 洞，洞的 `relation` 帶著那條關聯的兩端、連接欄位、經過的表與條件、出處與狀態。
  - 把問句原樣問使用者；確認後依 `relation` 自己寫出那一段，以 `fills` 再編譯。
  - 有寫入工具時以 `accept_relationship` 保存使用者的確認、以 `complete_relationship` 保存使用者給的連接欄位，進 Commit 區、發布後生效；沒有寫入工具時說明這次的確認只用在這份 SQL。
  - 被推翻的關聯每份 SQL 都重新問；編譯可能要等 Plasma 就地抽樣驗證。
- 修正 `scripts/test_package.py` 只執行第一組測試的問題，所有測試組都會執行。
