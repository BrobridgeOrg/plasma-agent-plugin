# v0.20.1

- 對話修改：由主代理在回答文件裡用 `revise_rule` 寫出新版本，先把回覆的 `reading`（新版本的中文讀法）給使用者確認，確認後才 `finish_document` 送進 Commit 區；不同意就不送。
- 版本衝突新增 `read_rejected`：用 `lookup_knowledge` 讀過的版本後來被拒絕，依目前版本檢查依它寫的內容。
- `withdraw_mapping`：已發布對應的撤銷列在回覆的 `staged`，在 Commit 頁發布後才生效；只帶 `entities` 時，沒有欄位對應依賴的實體連資料表一併撤回（`entity:<名稱>`）。
