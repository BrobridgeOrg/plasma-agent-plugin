新增 Windows 預編譯執行檔，Windows 使用者不必再改走 WSL。

- 發布內容新增 `windows/amd64` 與 `windows/arm64`，封裝名稱為 `plasma-plugin-mcp.exe`；Windows 不會執行沒有 `.exe` 副檔名的檔案。
- 啟動器辨識 Git Bash、MSYS2 與 Cygwin（`MINGW*`／`MSYS*`／`CYGWIN*`），取用對應的 `.exe` 並快取到 `~/.plasma-plugin/bin/v<version>/windows-<arch>/`。走 WSL 的使用者維持沿用 linux 版本，行為不變。
- Windows 會鎖住執行中的執行檔，安裝時的更名若輸掉競態、而快取已經就位，視為成功而非失敗。
- 讀取 `checksums.txt` 時接受 binary mode 的 `*` 檔名前綴（Git Bash 的 `sha256sum` 預設輸出格式），發布端也統一正規化成兩個空白的格式。
- 發布流程新增 windows-latest 的 smoke 測試：Windows 執行檔在 Linux 上交叉編譯，發布前先在真正的 Windows 上安裝並執行過打包好的檔案，未通過就不發布。

macOS 與 Linux 的行為沒有變動，既有的 `config.env` 與 `state.json` 不受影響，不需要重新設定。

驗證包含 Go 測試與建置、六個平台的交叉編譯，以及 Linux 與 Windows 兩份 smoke 測試。
