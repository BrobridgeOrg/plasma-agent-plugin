# v0.11.0

- `plasma-document-analysis`：新增「請使用者確認翻譯」。
  - 文件就緒後，主代理以 `read_translation` 取出概念段與對應段，原樣貼給使用者確認。
  - 使用者指出不對：依 `fragment_id` 以 `resume_item` 帶 `correction` 重開並修正，原文沒有的資訊先以 `submit_answer` 保存。
  - 使用者對資料對應沒有把握：`withdraw_mapping` 取消，之後由另一個人補 mapping。
- `plasma-fill-gaps`：使用者取消的對應由另一人重做 mapping；使用者指正翻譯時的修正流程。
