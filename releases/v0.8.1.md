# v0.8.1

- `plasma-create-bi` 的 PBIP 參考新增視覺類型對照表：20 種常用 `visualType` 與其角色名稱，整理自 Power BI Desktop 實際存出的官方 PBIR 樣本；不在表內的視覺改用最接近的類型，不再上網搜尋。
- KPI 卡片改用現行的 `cardVisual`（角色 `Data`）；`report.json` 的 `baseTheme` 改用 Desktop 實際寫出的值。
- 新增欄位／量值參照、排序與視覺標題的寫法範例；`$schema` 版本直接使用文件所列版本。
- 產生的 PBIP 與 HTML 檔案不寫任何註解，參考文件的範例也移除註解。
