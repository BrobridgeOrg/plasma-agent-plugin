# v0.4.0 — 新增 opencode 版本，連線走 OAuth

- 新增 opencode 安裝包 `plasma-plugin_0.4.0_opencode.zip`：同一份 skills，
  加上可合併的 `opencode.json` 連線設定與 `INSTALL.md`。
- opencode 走 OAuth：設定後執行 `opencode mcp auth plasma`，瀏覽器登入、選
  workspace、確認權限即完成，token 由 opencode 保管並自動更新，不需核發或複製權杖。
- `plasma-mcp-setup` 依宿主分成兩條路徑，並明確說明差別在用戶端而非伺服器。
- Claude Code 與 Codex CLI 維持存取權杖：兩者的 MCP SDK 不接受非 TLS 位址上的
  OAuth token endpoint；gateway 換上受信任的 HTTPS 憑證後也可改用 OAuth。
- skill 加上輸出約束：設定連線時只回報要做什麼與結果，不解說原理或列出檢查過程。

opencode 沒有 plugin marketplace，skills 以複製目錄方式安裝到
`~/.config/opencode/skills/`，詳見安裝包內的 `INSTALL.md`。
三個版本的 skills 內容完全相同，封裝測試會驗證這點。
