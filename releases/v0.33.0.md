# v0.33.0

- 文件分析（進階模式）：讀文件是代理的工作，系統只檢查並保存代理提交的產物。跟著改的說明：
  - 關聯的基數與連接鍵由代理填進 `cardinality`（或 `stated`）與 `on`，系統只存送來的內容。
  - 文件的標題與代號用 `identify_document` 記下；別份文件靠這裡的代號引用它。
  - 每個產物的主詞（哪張表、哪一欄）寫在產物裡；標題與章節名稱不會替產物補上主詞。
  - 原文的連結與文件代號由代理以 `declare_reference` 宣告，系統保存的引用就是宣告的這些。
- 文件分析（進階模式）：`also_states` 改成依已提交的產物提醒。新增一種：`data_note` 沒帶 `subject_table` 時提醒，講的是某張表就帶表名重送並收回原本那則。
- console 的「業務規則」「IT 規則」合併成「規則」分頁，說明裡的頁面名稱跟著改。
- 需要同版的 Ophion（分支 `refactor/program-does-not-read-the-document`）；儲存格式有變動，既有的進階模式 workspace 要重建。
