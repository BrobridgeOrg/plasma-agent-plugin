# v0.7.0

- 以 `plasma-create-pview` 取代建立 view skill，維持三份共用 skills。
- 預設在 mview 完成運算，以 pview 提供參數篩選；明確指定 mview 時以 mview 為最終輸出。
- 新增同步與定期排程流程，執行前由 skill 等待使用者明確確認。
- 收錄 pview 參數、查詢回應及同步排程的 API／工具格式參考。
- 資料 API 由使用者自行建立，plugin 不發布或匯出。

部署需使用支援 pview／排程工具的 MCP gateway，設定 `tool_profile = "bi"`。
同步確認為 skill 軟限制，沒有新增後端強制核准。
手動安裝升級時移除舊 `plasma-create-view` 目錄，並重新開啟 session。
