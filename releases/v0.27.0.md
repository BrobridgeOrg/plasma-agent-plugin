# v0.27.0

- 文件分析（進階模式）改成不經片段：讀文件後直接提交，每筆提交在 `source` 寫明出處（文字檔的行號 `lines`，表格列加 `cells`）與陳述模式（`statement`），原文由程式依行號切出。不再有審閱、開片段、結束與存檔的步驟。
- 每次 `submit_rules` 都是新增；改已收下的規則用 `revise_rule`，拿掉產物用 `delete_knowledge`，都以 id 指名，其他產物不受影響。
- 回覆的 `also_states` 是提醒：原文有說就補交，不留待補。
- `declare_reference` 自己帶引用的原文、種類與指向，回覆 `ref_id`；等引用的缺口用 `report_gap` 的 `waits_on`。
- `finish_document` 多列 `rejected_unanswered` 與 `unread_references`；`confirm` 只對上一則回覆列過的項目生效；`discard` 放棄整份工作。
- 補缺口：`resume_item` 開的是項目所屬文件的一份工作，回覆列出相關的產物；逐項補、改、刪，沒有點名的產物原樣保留。
- 需要同版的 Ophion（分支 `feat/fragmentless-extraction` 以後）：舊版知識服務沒有 `source` 欄位，新版不再有 `review_units`、`begin_fragment`、`finish`、`close_fragment`、`defer_fragment`。
