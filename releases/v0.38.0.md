# v0.38.0

- 查知識（進階模式）：`read_knowledge` 的 `search` 改成清單：`concepts` 逐筆帶種類、實體、狀態與一句話說明；沒有找到概念時，`near` 列出名稱最接近的概念（不同說法、多字或少字也找得到），`next` 說下一步。
- 查知識與出報表（進階模式）：新增 `read_knowledge` 的 `trace`：一次讀完一個指標或條件往下用到的全部知識（每個概念一次、讀自哪些欄位、還缺什麼、實際生效的樣子，以及文件對全篇的附註）；組請求前先讀它，需要規則原文時再用 `definition`。
- 出報表（進階模式）：題目對編譯結果還有要求（欄名、兩欄的比率、部分欄位或部分列、民國年與格式、排序）時，寫成 `compile_query` 的 `outer`（只讀 `report` 的 `SELECT`），執行回覆裡包好、經 Plasma 驗證的 `sql`；不再自己把編譯出的 SQL 抄進外層。代碼名稱的核准補充也放在 `outer`。
- 需要 Ophion `feat/agent-reading-load`（`search` 清單與 `near`、`trace`、`compile_query` 的 `outer`）。
