Plasma and Ophion MCP servers now run without installing Go or compiling locally.

- The launcher downloads the binary matching plugin v0.1.1 and the host platform, verifies SHA-256, and caches it outside the plugin directory.
- Includes macOS and Linux binaries for arm64 and amd64; the same executable provides both MCP servers and the consent hook.
- Supports authenticated downloads through GitHub CLI for private repositories, and offline installation through `PLASMA_MCP_RELEASE_DIR`.
- Local development uses `make build` and an explicit `PLASMA_MCP_BINARY` override.
- MCP configuration is included in the plugin manifest.

Install or update the plugin from `BrobridgeOrg/plasma-agent-plugin`. Existing configuration in `~/.plasma-plugin/config.env` is reused.

For private repository downloads, authenticate with `gh auth login`. Alternatively, download your platform's archive and `checksums.txt` from this release into one directory, then set `PLASMA_MCP_RELEASE_DIR` to that directory when launching Claude Code. Go, Node.js and Docker are not needed to run the downloaded binary.

Native Windows is not included; WSL uses the Linux binaries.
