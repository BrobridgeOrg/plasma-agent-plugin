# v0.9.0

- 新增 skill `plasma-document-analysis`：把文件交給進階模式的 Plasma 知識庫分析。使用者以一次性網址上傳，agent 整份讀取、摘錄規則並標注出處行號，處理衝突與未引用行、完成 mapping，再請使用者到 Commit 頁逐條勾選並確認發布。
- 新增 skill `plasma-fill-gaps`：查詢待補項目、轉交使用者的回答、以後到的文件或回答補齊缺口；事實衝突由使用者在 Commit 頁裁定。
- `plasma-mcp-setup` 的權限表加入 `knowledge:write`（只在進階模式提供）。
- 兩個新 skill 需要接上進階模式 ophion 的 Plasma；一般模式的 Plasma 不提供這些工具。
