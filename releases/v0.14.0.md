# v0.14.0

- 新增「查 Plasma 知識庫」（`plasma-knowledge-query`），取代 `plasma-knowledge-lookup` 與 `plasma-storage-lookup`：
  - 依工具清單判斷知識庫是一般模式或進階模式，走對應的查法。
  - 內含 sql-path：兩種模式「從知識取得驗證過的 SQL」的做法，交出相同的結果（SQL、說明、依據、假設、缺口），供建立 pview 與出報表共用。
  - Plasma SQL 寫法集中在一份（`sql-path/plasma-sql.md`），一般模式撰寫 SQL 與進階模式補洞共用。
- 代碼名稱缺漏時的候選補充改為兩種模式共用（`plasma-knowledge-query/references/code-names.md`）：進階模式先讀實體層附註的代碼意義，核准的名稱在編譯出的 SQL 外層以 `CASE` 套用；建立 pview 與建立 BI 都改連到這份說明。
- 「建立 pview」（`plasma-create-view`）支援進階模式：mview 的運算 SQL 由 `compile_query` 編譯，不帶 `as_of` 與 `window`，期間寫成分組留給 pview 篩選；多個指標以 `UNION ALL` 或 `FULL OUTER JOIN` 合成一份 SQL。
- 「出報表」（`plasma-report`）的找概念、編譯與補洞移到進階模式的 sql-path，本身只負責執行與交出結果。
- 只限進階模式的 skill（文件分析、補齊缺口、重新對應、出報表）開頭先判斷模式：在一般模式的系統被觸發時，說明一般模式該怎麼做（例如文件請在 Plasma 介面上傳）並結束，不要求重新授權、不繞路。
- `plasma-mcp-setup` 核對連線時一併說明知識庫的模式，並列出連線後可接續的技能。
- 升級：手動複製安裝的使用者請移除舊的 `plasma-knowledge-lookup` 與 `plasma-storage-lookup` 目錄。
