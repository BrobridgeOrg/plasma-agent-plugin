# v0.22.0

- 文件分析對齊儲存概念：表格文件的欄位列宣告該欄的儲存概念，橋接由程式產生；業務用詞另開概念，以定義規則讀儲存概念。
- 開片段時填陳述模式（內容類型、進件管道、模式），程式蓋到該片段的每筆產物。
- `finish_document` 的 `existing_definition`（別份文件已定義同一概念）與 `rule_checks` 的處理方式；保留的定義在 Commit 頁列出理由、不擋發布。
- 交給使用者時提醒 Commit 頁的版本規則事實衝突。
- 新 skill `plasma-code-notes`：agent 讀程式碼、DDL 或資料庫物件，把知識寫成筆記（陳述、逐字片段、出處、模式同一段），以穩定路徑 `user-notes/<repo>/<模組>.md` 上傳分析；程式改版重寫同一路徑。
