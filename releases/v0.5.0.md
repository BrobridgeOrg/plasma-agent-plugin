# v0.5.0 — 全面改用 OAuth，授權簡化為兩步

- 三個宿主一律走 OAuth：opencode、Claude Code、Codex CLI 都由宿主開啟瀏覽器完成授權，
  token 由宿主保管並自動更新，使用者不需要核發或複製任何憑證。
- 授權流程簡化為**登入 → 選 workspace**：選定即完成，不再有權限確認頁，
  每次授權都取得該部署支援的完整權限。
- 設定檔不再需要（也無法）指定 scope，權限由 gateway 決定；相關範例已移除。
- 移除手動存取權杖（PAT）的所有說明；該功能已在 backend 撤回。
- `plasma-mcp-setup` 依宿主列出設定與授權方式，並加入兩項實測得到的排除步驟：
  授權網址必須使用當次 `mcp auth` 印出的那一個，以及瀏覽器擋住導回本機時該怎麼辦。
- 後端待辦：B8（challenge scope）已隨本次一併完成，B9（HTTPS）仍未解。

## 需要同時部署的 backend 改動

本版對應 `plasma-backend` 的授權流程調整：consent 頁移除、授權一律授予完整 scope、
401 challenge 改為宣告完整 scope。**舊版 backend 搭配本版 plugin，
使用者仍只會拿到 `views:read`。**

## 部署前提

gateway 必須提供用戶端信任的 HTTPS 憑證，否則授權無法完成：Chrome 142 之後會擋下
由內網位址導回 `127.0.0.1` 的跳轉，而且不顯示任何提示——要求該權限的資格僅限
HTTPS 頁面。自簽而未把 CA 佈到用戶端不算受信任。
