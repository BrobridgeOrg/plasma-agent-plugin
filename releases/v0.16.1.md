# v0.16.1

- 進階模式補洞的說明照編譯回覆修正：
  - 送 `fills` 時帶給出這些洞的那次編譯的 `compile_id`：同一個請求前後兩次編譯，洞可能不同。
  - 有洞時回覆沒有 SQL，表名照 `read_schema` 寫，`expects.rows` 列到的實體一律讀它的 `from`。
  - 單位的洞填一個正數。
  - 補齊後的 `sql` 通常是最佳化過的版本，驗證不過時退回逐段寫的版本（`optimized` 為 false）。
  - `validation.valid` 為 false 時，錯誤不在片段就不要改片段，如實告訴使用者。
  - `read_schema` 的搜尋回 `has_more` 而沒有 `cursor` 時，縮小搜尋的字詞再查。
