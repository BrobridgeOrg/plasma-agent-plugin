# v0.26.0

- 新增入口技能 `plasma-guide`：使用者問 Plasma 能做什麼、可以怎麼開始時，先以 `whoami` 與 `overview` 看這個 workspace 的模式、權限與內容，列出現在能做的事（查資料表與欄位、查業務規則、依規則取得資料與報表、BI、上傳文件、補缺口），使用者選定後交給對應的技能。知識庫還沒有規則時先建議上傳文件。
- 查知識（進階模式）：問有哪些資料庫與資料表時用 `overview`，帶 `database` 列出那個資料庫全部的表名；資料庫與表以已發布的 schema 為準。
- 查知識（進階模式）：某張表或某個欄位的全部附註用 `read_schema` 的 `table` 讀，帶 `column` 讀單一欄位的完整描述、每則附註與出處；計算欄回它的公式。
- plugin 的說明與 Codex 的預設提示補上知識查詢、文件分析與入口。
- 對使用者只說明這個系統有的功能：`plasma-mcp-setup` 不再比較兩種知識庫，也不再列出另一種知識庫才有的流程；`plasma-guide` 依工具清單只讀這個系統自己的那一頁。尚無已發布知識時改依查知識的技能處理。
- 進階模式的 `overview` 與 `read_schema` 的 `column` 需要 Ophion edd62686 以後。舊版知識服務沒有 `overview` 時，技能略過這一步並說明列不出完整清單。
