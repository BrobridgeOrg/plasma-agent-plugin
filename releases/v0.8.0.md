# v0.8.0

- 新增 `plasma-create-bi`：以 pview 為來源產生 Power BI 專案（PBIP，TMDL 語意模型與 PBIR 報表）或單一 HTML BI 頁面；來源可接續本 session 建立的 pview，或由使用者指定 pview 名稱。
- `plasma-create-pview` 改由 mview 彙總到報表呈現粒度（期別 × 區塊 × 維度值），pview 不再回傳逐筆明細；建立前估算回傳筆數，並以最大參數範圍驗證低於下游上限。
- 不可加總指標（去重人數、比率、排名等）在 mview 各期別內完整計算，交付時標明不能跨列相加或平均。
- 同步確認改為固定格式，名稱一律使用 Plasma 回傳的 name。
- skill description 只描述觸發時機與範圍，執行規則集中在正文；補充 pview（Parameter View）與 mview（Materialized View）全稱。

手動安裝升級時複製新的 `plasma-create-bi` 目錄，並重新開啟 session。
