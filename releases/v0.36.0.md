# v0.36.0

- 查詢（進階模式）：
  - 洞帶著已發布知識對它說的 `gap_details`、`related` 與 `column_notes`，先讀再補；每一列的值不收常數，使用者說每列都相同時才帶 `constant`。
  - 同一個 `compile_id` 的補洞會累積：只送新的或改正的，送 `""` 清掉；`expects.write` 為 `choice` 的洞以 `choose` 回答。
  - 指標所屬群組的規則自動套用並寫在 `reading` 與 `basis.group_rules`；使用者明說不要時以 `scopes` 取消。條件式讀法、退役表與敏感欄位也列在 `basis`。
  - `read_knowledge` 的 `definition` 附實際生效的樣子（`effective`）；`dimensions` 列出指標能依什麼分組。
  - 使用者確認後才寫回：補洞的用 `keep_fills`，自己依規則寫的 SQL 用 `keep_agreed`，都帶使用者原話。
- 文件分析（進階模式）：新增「一句話放在哪裡」：`submit_group`（group、scope、event_time、measure_convention、value_entity、crosswalk、classification）、`submit_annotation` 的 `conditional_reading`、`table_standing`、`sensitive`，與 `submit_backbone` 的 `format`。
- mapping：三種情況以 Plasma 的 `profile_column` 抽樣探測，結論以 `data_probe` 提交，進 Commit 區為「資料推測」。
- 補齊缺口：新增 `coverage:`、`answer-fill:`、`probe-conflict:` 三種待補項目的處理。
- 需要同版的 Ophion（分支 `feat/storage-batch2`）與 Plasma（分支 `feat/profile-column`）。
