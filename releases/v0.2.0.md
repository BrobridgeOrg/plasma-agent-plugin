兩台 MCP server 都移到 plasma-backend 了。

Plasma 的控制面與 Ophion 的知識工具現在由 plasma-backend 的 `mcp_gateway` 一起
提供：一台 HTTP MCP server，前面是它自己的 OAuth 2.1。使用者加一個 URL、在瀏覽器
登入一次、選一個 workspace，兩半就都有了；不需要複製貼上 token，也不可能把 Plasma
與知識指到不同的 workspace —— workspace 寫在同一張憑證裡。

- **移除** `plasma` 與 `ophion` 兩台 stdio MCP server，以及它們的設定
  （`~/.plasma-plugin/config.env`、`state.json`、`bin/plasma-config.sh`）。
  這個 plugin 現在沒有任何設定，也不持有 endpoint 或憑證。
- **保留** PreToolUse 確認閘。gateway 的授權是連結時一次給定 scope，之後不再詢問，
  所以同步、開 API、執行匯出前的確認只能從用戶端這側來。
- `plasma-postgres-export` skill 更名為 `plasma-export`，不再綁定 PostgreSQL；
  `plasma-plugin-setup` 更名為 `plasma-mcp-setup`，內容改成如何連上 gateway。
- 沒有 `use_workspace` 了。workspace 在授權時選定並寫進憑證，要換就重新連結。

**升級後要做的事**：移除舊的 `plasma`／`ophion` MCP server 設定，改用
`claude mcp add --transport http plasma https://<gateway>/mcp`，然後跑一次
`whoami` 確認連到的 workspace 與權限。`~/.plasma-plugin/` 可以整個刪掉。
