# v0.25.0

- 文件分析：同一段摘錄的同類註記可以整批送。`submit_annotation` 與 `submit_backbone` 接受 `items`（產物清單），共用的欄位（`kind`、`cells`）寫在 `items` 旁邊一次；一張欄位表或一份代碼表一次呼叫送完。
- 整批提交逐筆檢查：通過的先收下，被拒的依原因列出各筆編號，只修正那幾筆再送。一次呼叫處理 50 筆，其餘由 `not_read` 指出從第幾筆起再送。
- 規則（`submit_rules`）仍然一次一條。
- 需要 Ophion e35e9dbe 以後。舊版伺服器不認得 `items`，會拒絕整批提交。
