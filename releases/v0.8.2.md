# v0.8.2

- 修正 1,000 筆限制的適用範圍：只限制 pview 每次篩選後的完整結果，不限制 mview 的資料準備、儲存量或歷史範圍。
- 新增 Power BI MCP 建模、匯出、讀回與刷新驗證流程，補齊 API 格式、日期參數及 DAX 表名處理規則。
- 日期／月份報表提供前端選擇器，所有指標與圖表同步篩選；明確區分 Import 已載入資料的切換、重新整理與 DirectQuery 動態參數。
- 改善 PBIR 呈現規則：人次顯示完整數字、移除技術註記與重複標籤，並處理長名稱與文字遮擋。
- 新增 Desktop 實際畫面與月份切換驗收，避免將模型或 schema 驗證成功視為完整報表驗收。
