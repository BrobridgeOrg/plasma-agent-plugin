# v0.3.2 — 改用存取權杖連線

- 連線方式改為 gateway 的 `/oauth/pat` 核發存取權杖：使用者以 Plasma 帳號登入、
  選 workspace、逐項勾選權限，再把權杖放進環境變數並設定用戶端。
- `plasma-mcp-setup` 改寫為逐步引導流程，移除宿主 OAuth 登入與 HTTPS endpoint 說明。
- 權限不足改為重新核發並勾選需要的 scope；新權杖不繼承舊權杖的權限。
- 診斷改以權杖語彙描述：401、核發頁無法開啟、權杖過期或被撤銷。
- README 對象改為 Claude Code 與 Codex CLI，移除 ChatGPT 網頁版連線與上架章節。
- 後端待辦清單標示目前路徑為 B7，網頁版相關項目暫緩但保留紀錄。

本版需要後端開啟 `pat_enabled`；未開啟時 `/oauth/pat` 不存在，沿用既有連線即可。
ChatGPT 網頁版暫不支援：它由 OpenAI 伺服器連出，連不到內網 gateway 位址。
更新後開新對話／session，避免沿用已載入的舊版流程。
