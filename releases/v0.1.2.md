三份 skill 統一使用台灣繁體中文，並調整表單轉資料 API 的流程。

- 進度、問題、確認、錯誤說明及交付內容均使用台灣繁體中文；SQL 與識別名稱保留原樣。
- 知識查找、欄位查核、SELECT 驗證及建立 manual mview 不再由 plugin 強制逐步確認。
- 確認集中在開始同步拉資料與同步成功後開啟 API。同步確認會說明執行後將從來源系統拉取資料並寫入／更新 mview；API 確認會說明資料範圍、驗證方式及有效期限。
- scheduled create_view 會立即啟動同步，因此仍須在執行前確認，並說明後續排程。
- 原則上一份表單／報表建立一個 mview，整合各區塊、指標及來源表；只有使用者明確要求才拆分。
- run_query 以唯讀工具標示；SQL 驗證、Ophion 來源查核與知識缺口處理仍保留。

包含 macOS／Linux 的 arm64、amd64 預編譯執行檔與 SHA-256 校驗檔，不需要在使用者電腦安裝 Go。更新 plugin 後，launcher 會使用 v0.1.2 的獨立快取。

宿主平台的工具權限仍適用。ChatGPT／Codex 不應依賴 Claude hook 的 permissionDecision: ask，需使用其支援的工具確認設定。
